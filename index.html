WEB115 課程進度清單

從純手刻 HTML/CSS 骨架，過渡至 Bootstrap 響應式佈局，掌握背景視差固定與 Sticky 定位機制，再逐步深入捲動量化與數位敘事。以下依照難易度由淺入深排列。

學習進度：0 / 26
  • LEVEL 01 基礎手刻
    HTML + CSS 純手刻基礎 (Hand-Crafted Basics)

    不依賴任何外部框架，從零親手撰寫語意標籤、盒模型與多區塊滾動排版，奠定網頁底層基礎。

    ★☆☆☆☆ 入門 ▼
    • 01.1 HTML 語意化結構與頁面骨架

      建立基本文檔標準聲明、視窗縮放設定，以及掌握各區段標籤的結構職責。

      <!DOCTYPE html> <header> <nav> <section> <main> basic.html ↗
      • <meta name="viewport"> 的標準縮放配置與行動端閱讀相容性
      • 使用 <section> 與 id="scene01" 切分敘事場景
    • 01.2 CSS 盒模型與樣式基礎

      深入理解外距 (margin)、邊框 (border)、內距 (padding) 與內容寬度的盒模型計算，並使用 Flexbox 進行空間對齊。

      box-sizing: border-box margin / padding display: flex style.css ↗
      • 全域樣式重設與 box-sizing: border-box 避免寬度超出
      • 透過手刻 CSS 實現置中、雙欄與三欄佈局
    • 01.3 多場景手刻捲動與錨點導覽

      手刻包含 Banner、側欄 Nav、主要內容區與 Supporting 區塊的長頁面，利用錨點實現頁內平滑定位。

      <a href="#scene01"> scroll-behavior: smooth basic.html ↗
      • 錨點點擊後的頁內跳轉與邊界留白處理
      • 手刻結構如何為後續引入框架做準備
  • LEVEL 02 響應式框架
    Bootstrap 框架與響應式格線 (Bootstrap Foundations)

    從純手刻過渡至主流 UI 框架，利用 Container-Row-Col 格線系統與 Utility 工具類別快速建構響應式頁面。

    ★★☆☆☆ 基礎 ▼
    • 02.1 引入 Bootstrap 核心 (CDN & Reboot)

      透過 CDN 引入現代 Bootstrap 樣式表與 JavaScript Bundle，理解其預設重設與 Typography 設定。

      <link bootstrap.min.css> bootstrap.bundle.min.js bt.html ↗
    • 02.2 12 格線系統與響應式斷點 (Grid & Breakpoints)

      運用 .container、.row 與斷點欄位配置（sm, md, lg），依視窗大小自動調整並排或堆疊欄位。

      .container / .container-fluid .row .col-sm-6 .col-md-4 bt.html ↗
      • 雙欄自適應：例如左欄 4 格、右欄 8 格的報導圖文排版
      • 不同螢幕尺寸的自動斷行與間距維持
    • 02.3 Utility 類別與快速組裝 Banner

      利用間距類別（p-5, mt-5）、背景色彩（bg-primary, bg-light）及對齊工具迅速組裝報導 Hero 首頁橫幅。

      .p-5 .mt-5 .bg-primary .text-white .text-center bt.html ↗
  • LEVEL 03 視差基礎
    Bootstrap 背景圖片與 background-attachment: fixed

    結合全視窗高度（vh-100）與固定背景圖層，創造出文字內容在靜態景深上滑過的初階視差捲動效果。

    ★★☆☆☆ 基礎 ▼
    • 03.1 滿版視窗高度與背景填滿 (vh-100 & background-size)

      使用視窗單位 100vh 建立全螢幕區塊，配合 cover 與 center 讓高畫質影像適應各種螢幕長寬比。

      height: 100vh / .vh-100 background-size: cover background-position: center bt2.html ↗
    • 03.2 核心語法：background-attachment: fixed

      改變背景圖片的定位參照對象，使其固定於瀏覽器視窗（Viewport），頁面捲動時僅文字內容位移，背景維持靜止。

      background-attachment: fixed background-repeat: no-repeat bt2.html ↗ scrolling-lab.html #fixed ↗
      • 比較 scroll（隨文檔滾動）與 fixed（釘在視窗）的空間運動感
      • 在行動裝置或特定瀏覽器上的繪圖效能與相容性考量
    • 03.3 多場景固定背景交替敘事 (Multi-Scene Parallax)

      串聯多個連續的 100vh 固定背景區塊（如主角人物寫真、故事場景切換），形成宛如窗景切換的故事流。

      #first / #second .container-fluid.vh-100 bt2.html ↗
  • LEVEL 04 定位與吸頂
    捲動固定定位：Sticky-top 與吸頂機制

    解析元素在捲動至視窗邊緣時吸附頂端的物理原則，包含父容器約束邊界以及防止版面塌陷的佔位機制。

    ★★★☆☆ 中階 ▼
    • 04.1 position: sticky 與 Bootstrap .sticky-top 原理

      理解 sticky 與純 fixed 的本質區別：sticky 在達到閾值前保持自然流動，接觸邊緣後暫時固定，不脫離常規文檔流。

      position: sticky top: 0 .sticky-top sticky-top-prompt.html ↗ scrolling-lab.html #sticky ↗
    • 04.2 父容器約束邊界 (Parent Boundaries)

      深入剖析 sticky 元素的活動極限：其吸頂行為僅在其父容器（Parent Container）可見範圍內生效，父層滾出時元素被推走。

      parent container overflow: hidden (avoid) scrolling-lab.html #sticky ↗
      • 常見錯誤除錯：父層設置 overflow: hidden 會導致 sticky 立即失效
      • 如何利用長度高達 300vh 的父容器打造長時間停留的固定展示窗
    • 04.3 動態吸頂與 Placeholder 佔位防抖動

      當透過 JavaScript 或滾動偵測將元素切換為 fixed/sticky 時，使用隱形佔位元素（Placeholder）避免下方內容突兀跳動。

      .fixed-top-placeholder $(window).scrollTop() .is-fixed { position: fixed } sticky-top-prompt.html ↗
  • LEVEL 05 量化與機制
    捲動物理與進度度量 (Scroll Mechanics & Lab)

    解構可捲動距離的數學關係，將縱向滾動比例轉化為橫向進度條、物件平移動畫與三層橫向捲動。

    ★★★☆☆ 中階 ▼
    • 05.1 可捲動距離與數學模型 (Scroll Dimensions)

      釐清文件高度 (Document Height)、視窗高度 (Viewport Height) 以及最大有效可捲動距離的計算公式。

      maxScroll = docHeight - winHeight scrollTop scrolling-lab.html #distance ↗
    • 05.2 縱向捲動比率映射橫向進度條 (Status Bar)

      將 0 到 1 的捲動進度比率（scrollRatio）即時反映在橫向進度條的寬度百分比上，為長篇報導提供視覺指引。

      ratio = current / max width: ${ratio * 100}% scrolling-lab.html #status ↗
    • 05.3 複合場景：Sticky-top + 局部進度條

      把吸頂場景與進度條結合，當捲動進入特定章節時顯示該幕專屬的閱讀進度，離開時順暢銜接下一幕。

      scene progress sticky container scrolling-lab.html #combined ↗
    • 05.4 捲動比率轉物件位移 (Moving Objects)

      以捲動量驅動視覺元件（如車輛、人物、指標）在軌道上平移，計算物件自身寬度對最大可移動距離的影響。

      transform: translateX(...) will-change: transform scrolling-lab.html #moving ↗
    • 05.5 三層結構解構橫向捲動 (Horizontal Scrolling)

      拆解經典橫向捲動三層：外層垂直滾動高度容器、中層 Sticky 吸頂視窗、內層橫向位移軌道。

      height: 400vh (Outer) position: sticky (Middle) width: 400% (Inner Track) hcroll-antigravity.html ↗ scrolling-lab.html #horizontal ↗
  • LEVEL 06 頁面控制
    Slide Effect 滑頁與長頁混合 (Slide & Hybrid)

    從最簡的滾輪接管滑頁出發，處理包含長文章的混合捲動問題，並對比 GSAP 與原生 Scroll Snap 實作。

    ★★★★☆ 進階 ▼
    • 06.1 最簡滾輪滿版滑頁 (Minimal Wheel Slideshow)

      監聽滾輪事件搭配 translateY 與 CSS transition，將連續滾動轉換為整頁式投影片切換。

      $(window).on('wheel') transform: translateY(-N * 100vh) slideshow.html ↗
    • 06.2 滑頁架構中嵌入長頁 (One Long Page within Slides)

      突破「所有投影片皆為一幕」的限制，當某一頁內容過長時，保留內部自然捲動，到底後才觸發換頁。

      overflow-y: scroll boundary detection slideshow-long-page.html ↗ slide-effect-long-page.html ↗
    • 06.3 原生 CSS Scroll Snap vs GSAP 動畫庫對比

      比較原生純 CSS 吸附機制（零 JS、高流暢度）與專業動畫函式庫（精確緩動、手勢攔截）的實務取捨與操作手感。

      scroll-snap-type: y mandatory scroll-snap-align: start gsap.to() slideshow-scroll-snap.html ↗ slideshow-gsap.html ↗
    • 06.4 現代重構版：滑動切換與長內容頁混合

      運用現代語法重構 slide effect，優化過渡動畫與觸控反應，解決回滾卡頓與邊界判定難題。

      modern event handling smooth transitions slide-effect.html ↗
  • LEVEL 07 綜合敘事專案
    數位敘事綜合案例 (Scrollytelling Projects)

    結合地圖、3D 建築模型、群像像素動畫與多層景深視差，將前述所有捲動機制融會貫通為完整數位報導作品。

    ★★★★★ 專題 ▼
    • 07.1 臺灣選舉版圖 Scrollytelling (固定地圖與文字互動)

      左側或背景固定互動式臺灣 22 縣市地圖，右側滾動敘事文本，隨滾動進度動態觸發縣市浮起、顏色切換與數據圖表。

      SVG Map Scrollytelling step-driven highlighting taiwan-election-scrolly.html ↗
    • 07.2 3D 建築空間導覽 (Three.js 樓層模型與平滑視角切換)

      先獨立建立臺大新聞所 3D 結構模型，再結合捲動控制攝影機鏡頭軌跡，隨讀者閱讀進度平滑穿梭各樓層。

      Three.js WebGL camera position interpolation ntu-journalism-3d-standalone.html ↗ ntu-journalism-scroll-story.html ↗
    • 07.3 100 個資料點的動態重組敘事 (Data Point Grid)

      用 100 個點代表 100%，隨滾動平滑位移並重新分組聚合成不同群組，生動呈現學生背景、入學方式與職涯比例變化。

      CSS Grid / Particle reposition data storytelling ntu-journalism-student-story.html ↗
    • 07.4 像素人物群像與社會分化 (Pixel Crowd Story)

      結合 100 位像素人物圖像與捲動序列動畫，隨捲動呈現人群從多元聚集、逐漸同質化到最終分為兩大陣營的情感張力。

      pixel art sprite animation narrative pacing pixel-crowd-story.html ↗
    • 07.5 多層景深視差捲動 (Multi-Layer Parallax: Aladdin)

      將遠景天空、中景雲層建築、主角人物與前景樹石拆為多層，依距離賦予不同位移速率，呈現電影級的立體空間滾動體驗。

      multi-layer depth layering parallax scroll speed ratio parallax-scrolling-alladin/index.html ↗
